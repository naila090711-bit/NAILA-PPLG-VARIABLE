C. Aktivitas 1 — Eksperimen 10 + 20

let a = "10";
let b = "20";
console.log(a + b);

1. Apa output program?

1020

2. Mengapa hasil tersebut terjadi?

Karena a dan b bertipe String, sehingga tanda + menggabungkan teks, bukan menjumlahkan angka.

3. Apakah a dan b bertipe Number?

Tidak, keduanya bertipe String karena nilainya menggunakan tanda kutip.

Hasil uji dan penjelasan:

Prediksi saya benar. Output-nya 1020 karena kedua nilai merupakan String.

D. Aktivitas 2 — Menemukan Tipe Data

let nama = "Asep";
let umur = 16;
console.log(typeof nama);
console.log(typeof umur);
Variabel Prediksi Hasil typeof Kesimpulan
nama String string Berisi teks
umur Number number Berisi angka

Temuan:

String digunakan untuk menyimpan teks, sedangkan Number digunakan untuk menyimpan angka yang dapat dihitung.

E. Aktivitas 3 — Konversi String Menjadi Number

let a = "10";
let b = "20";
let hasil = Number(a) + Number(b);
console.log(hasil);

Hasil program: 30

F. Aktivitas 4 — Program Kasir Sederhana

let harga = Number(prompt("Masukkan harga: "));
let jumlah = Number(prompt("Masukkan jumlah: "));
let total = harga * jumlah;
console.log("Total belanja = " + total);
Input Uji Nilai
Harga Rp10.000
Jumlah 2
Total seharusnya Rp20.000
Total program Rp20.000

G. Tantangan — Program Hitung Nilai

Algoritma saya:

  1. Meminta pengguna memasukkan nilai tugas, UTS, dan UAS.
  2. Mengubah semua input menjadi Number menggunakan Number().
  3. Menjumlahkan ketiga nilai.
  4. Membagi jumlah nilai dengan 3 untuk mendapatkan rata-rata.
let tugas = Number(prompt("Masukkan nilai tugas:"));
let uts = Number(prompt("Masukkan nilai UTS:"));
let uas = Number(prompt("Masukkan nilai UAS:"));

let rataRata = (tugas + uts + uas) / 3;

console.log("Rata-rata nilai = " + rataRata);

H. Think — Pair — Share

1. Mengapa prompt() perlu dikonversi jika hasilnya ingin dihitung?

Karena prompt() menghasilkan String, sehingga harus diubah menjadi Number agar dapat dihitung.

2. Apa perbedaan "10" dengan 10?

"10" adalah String atau teks, sedangkan 10 adalah Number atau angka.

3. Apa yang terjadi jika lupa Number()?

Input tetap berupa String. Jika menggunakan tanda +, nilainya dapat digabungkan, bukan dijumlahkan.

Pair:

Jawaban saya dan teman bisa sama atau berbeda karena cara menjelaskan berbeda, tetapi hasil percobaannya tetap sama.

Share:

Saya menemukan bahwa prompt() menghasilkan String sehingga perlu Number() jika input akan digunakan untuk perhitungan.
